# Frontend: Очередь обращений

Клиентская часть для сервиса «Очередь обращений». Представляет собой Single Page Application (SPA), которое позволяет создавать обращения и отслеживать их статус в реальном времени.

## Стек и обоснование

* **React 18 + TypeScript** — стандарт для современных SPA. TypeScript обеспечивает строгую типизацию данных, приходящих с бэкенда (схемы описаны в `src/api.ts`).
* **Vite** — Мгновенный старт dev-сервера и быструю сборку для продакшена.
* **TanStack Query (React Query)** — библиотека для управления серверным состоянием. 
  * *Зачем:* В ТЗ требуется автообновление статусов (polling). React Query реализует это через параметр `refetchInterval` в одну строку, автоматически управляя таймерами и кэшем. Также он предоставляет готовые флаги `isLoading`, `isError` для отображения состояний загрузки и ошибок.
* **Tailwind CSS (через CDN)** — для быстрой стилизации без написания кастомного CSS. Обеспечивает адаптивность интерфейса (карточки и форма корректно отображаются на мобильных устройствах).

## Запуск

### В составе Docker (Рекомендуется)
Фронтенд запускается вместе с остальным стеком из корневой папки проекта:
```bash
docker compose up --build -d
```

### Локальный запуск
```bash
cd frontend

npm install

npm run dev
```

Будет доступно по адресу `http://localhost:5173/`
